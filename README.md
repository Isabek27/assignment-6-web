# Assignment 6 — jQuery beginner project

Five pages with Task 0–11 for jQuery selectors, effects, DOM, animations and an accordion mini project.

## Run
Open `index.html` in your browser with an internet connection (jQuery is loaded from CDN). Use the navbar to switch between pages.

## Files
- `index.html`: Tasks 0–1
- `effects.html`: Tasks 2–4
- `dom.html`: Tasks 5–7
- `animations.html`: Tasks 8–10
- `project.html`: Task 11
- `script.js`: all jQuery code
- `style.css`: styles
